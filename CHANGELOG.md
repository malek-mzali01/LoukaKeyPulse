# Changelog

## [1.0.0] - 2026-11-13

### Added
- Repeats held keys and mouse side buttons at an interval from 1 ms to 5000 ms.
- Profiles with export and import.
- Target apps, per-key modifier rules and a global toggle key.
- System tray mode and single-instance protection.
- WoW chat detection with one-time calibration per client build.
- Calibration manager to recalibrate or delete saved builds.
- Automatic update check with changelog, Update now, Later and Skip this version.

## [1.0.1] - 2026-11-14

### Fixed
- M4/M5 side buttons sometimes not spamming (missed release events, very quick taps).
- Mouse hook is only active while M4/M5 spam is enabled and is refreshed automatically.
